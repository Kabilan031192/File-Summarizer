# 📄 AI File Summarizer

A beautiful web application that allows you to drag and drop multiple files and get instant summaries of their content.

## Features

✨ **Drag & Drop Interface** - Simply drag files from your desktop or file explorer
📁 **Multiple File Support** - Upload and analyze multiple files at once
📊 **File Analysis** - Get detailed information about file size, type, and content
🎨 **Beautiful UI** - Modern, responsive design with smooth animations
📝 **Content Preview** - View previews of text-based files
🔍 **Smart Detection** - Automatically detects file types and provides relevant summaries

## Supported File Types

- **Text Files**: .txt, .csv, .json, .xml, .html, .css, .js
- **Documents**: .pdf, .docx, .doc
- **Spreadsheets**: .xlsx, .xls

## How to Use

1. Open `index.html` in your web browser
2. Drag and drop files onto the drop zone, or click to browse
3. Click "Summarize All Files" to analyze your files
4. View detailed summaries for each file
5. Remove individual files or clear all at once

## Installation

No installation required! Just open the `index.html` file in any modern web browser.

### Quick Start

```bash
# Navigate to the project directory
cd file-summarizer

# Open in your default browser (macOS)
open index.html

# Or on Windows
start index.html

# Or on Linux
xdg-open index.html
```
