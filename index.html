📖 How to Use This App

Supported File Types:

  • DE-ANO Files: Calibration data with parameters from columns J-T
  • Gold Pad Files: Extended calibration data with parameters from columns J-U (includes X/Y table repeating accuracy)
  • Transcoding Files: Machine calibration data with spec validation
  • Polishing/Sanding Files: Robot cell calibration data
  • Deburring Files: Nozzle-based measurement data

Steps to Use:

  1. Upload Files: Drag and drop your Excel files (.xlsx, .xls) into the drop zone, or click to browse
  2. Review Files: Check the uploaded files list to ensure all files are loaded
  3. Summarize: Click "Summarize All Files" to analyze the data
  4. View Results: Review the detailed analysis including:
    • Document metadata (machine IDs, dates, etc.)
    • Parameter values with spec compliance
    • Pass/fail status for each parameter
    • Summary statistics
  5. Export: Download results as PDF or Excel for reporting

Key Features:

  • ✅ Automatic file type detection
  • ✅ Spec validation with color-coded results (green = pass, red = fail)
  • ✅ Support for merged cells and complex Excel structures
  • ✅ Scanner Calibration (X and Y axis) analysis
  • ✅ Multiple machine data in single file
  • ✅ Export to PDF or Excel format
